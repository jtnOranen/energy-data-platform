# 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-10-20

## Context

This is a portfolio project. Reviewers and interviewers care more about *why* than *what*.

## Decision

Record every lasting technical decision as a short ADR in `docs/adr/`, using `0000-template.md`.
An ADR is written in the same pull request as the change it explains.

## Consequences

Decisions are reviewable and defensible. Reversing one means writing a new ADR that supersedes it.
